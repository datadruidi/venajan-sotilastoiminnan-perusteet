# perustietoa venajan sotilastoiminnasta

markdown-pohjainen tietopaketti venajan puolustushaaroista, sotilaspiireista ja sotilasarvoista.

## rakenne
- `docs/` sisaltaa varsinaiset sisaltosivut.
- `images/` sisaltaa sivuilla kaytetyt kuvat.
- `sources/` sisaltaa lahde- ja kuvaviitetiedot.

## sisalto
- `docs/01-puolustushaarat/` puolustushaarat ja kalusto.
- `docs/02-sotilaspiirit/` sotilaspiirit, tukikohdat, joukot ja tunnukset.
- `docs/03-sotilasarvot/` sotilasarvot ja arvomerkit.

## yllapito
- lisaa uudet kuvat aina vastaavaan kansioon `images/`-puolella.
- pida `docs/`- ja `images/`-kansioiden nimet keskenaan samoina.
- lisaa tai paivita kuvien lahdetiedot `sources/`-tiedostoihin.

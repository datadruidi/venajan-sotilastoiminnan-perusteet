# docs

`docs/` sisaltaa repoon kuuluvat markdown-sivut.

paaosiot:
- `01-puolustushaarat/` kokoaa puolustushaarat ja kalustoa kasittelevat sivut.
- `02-sotilaspiirit/` kokoaa sotilaspiirit, tunnukset ja alueellisen rakenteen.
- `03-sotilasarvot/` kokoaa sotilasarvot ja arvomerkit.

jokaisessa paaosiossa sivut ovat suoraan `.md`-tiedostoina ilman sivukohtaisia alikansioita.
